Auth Endpoints

POST /_allauth/app/v1/auth/signup Register a new user ▼

Request body (JSON):

{ "email": "user@example.com", "password": "secure123", "full_name": "John Doe" }

Success 200 response:

{ "status": 200, "data": { "access": "eyJ...", "refresh": "eyJ..." } }

→ Then use POST /auth/email/verify with the 6-digit OTP code sent to email.

POST /_allauth/app/v1/auth/login Login with email + password ▼
{ "email": "user@example.com", "password": "secure123" }

Response:

{ "status": 200, "data": { "access": "eyJ...", "refresh": "eyJ...", "user": { "email": "...", "full_name": "..." } } }
DELETE /_allauth/app/v1/auth/logout Logout (invalidate session) ▼

Requires: Authorization Bearer token. No body needed.

DELETE /_allauth/app/v1/auth/logout Authorization: Bearer <access_token>
POST /_allauth/app/v1/auth/email/verify Verify email with 6-digit OTP code ▼
{ "key": "123456" }

Also supports PUT with empty body to resend the verification email.

POST /_allauth/app/v1/auth/password/reset Request password reset (sends OTP to email) ▼
{ "email": "user@example.com" }
POST /_allauth/app/v1/auth/password/reset/by_code Set new password using OTP code ▼
{ "email": "user@example.com", "code": "123456", "password": "newSecret99" }
POST /_allauth/app/v1/auth/password/change Change password (authenticated) ▼

Requires: Bearer token

{ "current_password": "oldPass", "new_password": "newPass123" }
POST /_allauth/app/v1/auth/token/refresh Refresh JWT access token ▼
{ "refresh": "eyJ..." }

Profile Endpoints

GET /api/me/ Get current authenticated user ▼

Requires: Bearer token

GET /api/me/ Authorization: Bearer <access_token>

Response (UserSerializer):

{ "id": 1, "full_name": "John Doe", "email": "john@example.com", "profiles": { "image": "/media/profile/pic.jpg", "phone": "+977..." } }
PATCH /api/me/profile/update Update profile image & phone ▼

Requires: Bearer token · Content-Type: multipart/form-data

PATCH /api/me/profile/update Authorization: Bearer <access_token> FormData: phone: "+977 9800000000" image: [file upload, optional]

Response (ProfileSerializer):

{ "image": "/media/profile/new.jpg", "phone": "+977 9800000000" }

Also supports GET (retrieve) and PUT (full update).
